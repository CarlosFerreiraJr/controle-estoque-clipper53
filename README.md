# Sistema de Controle de Estoque — CA-Clipper 5.3

Projeto desenvolvido em **CA-Clipper 5.3**, com o objetivo de revisitar tecnologias legadas e aplicar conceitos de programação estruturada, manipulação de arquivos DBF e desenvolvimento de sistemas comerciais em ambiente DOS.

## Funcionalidades implementadas

- Cadastro, consulta, alteração e exclusão lógica de produtos (CRUD).
- Geração automática de códigos.
- Validação de campos de entrada.
- Controle de bloqueio de registros com `RLOCK()` e `DBUNLOCK()`.
- Listagem de produtos com **paginação de 8 registros por página**.
- Menus interativos em ambiente DOS.
- Mensagens de erro, aviso e sucesso.

## Tecnologias utilizadas

- CA-Clipper 5.3
- Arquivos DBF
- Blinker Linker
- DOSBox-X
- Visual Studio Code
- Git e GitHub

## Próximas melhorias

- Rotina de manutenção e compactação dos arquivos DBF.
- Criação e gerenciamento de índices NTX.
- Aprimoramento do controle multiusuário.
- Novas funcionalidades de gerenciamento de estoque.
